Core Engine Capabilities

  • Catalog Aggregation: Fetches OpenRouter catalog and Artificial Analysis ratings into Neon PostgreSQL.
  • Multi-Modal Leaderboards: Aggregates Large Language Models, Image Generation, Video Generation, and Audio models.
  • Interactive Comparisons: Side-by-side spec, pricing, speed, and intelligence score comparison API.
  • Automated Backfill: Smart pipeline that guarantees 0% missing fields across context lengths, max completion tokens, pricing per 1M, and intelligence scores.

Architecture & Data Schema

RankLLMs Engine relies on Django 6.0 and Django Ninja for zero-overhead JSON serialization, connected to Neon PostgreSQL over SSL.

+-------------------------+ +------------------------------------+ | OpenRouter API Catalog | | Artificial Analysis Data API v2 | | (Models + Analytics) | | (LLM Benchmarks + Media Rating) | +------------+------------+ +-----------------+------------------+ | | v v [ openrouter_sync.py ] [ artificial_analysis_sync.py ] (Catalog & App Rankings) (Intelligence, Coding & Media) | | +-------------------+------------------+ | v [ fill_nulls.py ] (Backfills missing specs, pricing & benchmarks) | v +---------------------------+ | Neon PostgreSQL Database | +-------------+-------------+ | v +---------------------------+ | Django Ninja REST API v1 | +---------------------------+

REST API Endpoints

GET /api/v1/health System Health Check

Returns health status and live record counts from PostgreSQL.

curl -X GET "http://localhost:8000/api/v1/health"
GET /api/v1/models Models Catalog & Search

Filterable catalog. Query parameters: search, category, provider, is_free, is_open_weight.

curl -X GET "http://localhost:8000/api/v1/models?category=llm&is_open_weight=true"
GET /api/v1/leaderboard Leaderboards & Rankings

Returns ranked models. Parameters: sort_by (intelligence, coding, speed, price), category (all, open-llm, free, weekly-top-10).

curl -X GET "http://localhost:8000/api/v1/leaderboard?sort_by=coding"
GET /api/v1/compare Side-by-Side Model Comparison

Compares specs, cost, speed, and intelligence index between 2 models.

curl -X GET "http://localhost:8000/api/v1/compare?model_a=anthropic/claude-3.5-sonnet&model_b=deepseek/deepseek-r1"
POST /api/v1/sync Trigger Master Sync Pipeline

Triggers complete OpenRouter + Artificial Analysis + Null Backfill pipeline.

curl -X POST "http://localhost:8000/api/v1/sync"

Data Pipelines & APScheduler

RankLLMs Engine uses APScheduler running inside Django process to execute sync_all every 6 hours automatically.

# Manual CLI execution python manage.py sync_all

Deployment Options

Option 1: Render (Recommended)

Build Command: pip install -r requirements.txt && python manage.py migrate && python manage.py sync_all
Start Command: gunicorn config.wsgi:application --bind 0.0.0.0:$PORT --workers 3

Option 2: Docker Compose

docker-compose up -d --build

Option 3: Linux VPS (Hostinger / DigitalOcean / AWS EC2)

Use Gunicorn systemd service behind Nginx reverse proxy.

Local Development

# Setup virtual environment python -m venv venv .\venv\Scripts\activate # Install requirements pip install -r requirements.txt # Run migrations & server python manage.py migrate python manage.py runserver
