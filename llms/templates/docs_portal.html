Complete REST API Catalog (All Endpoints)

All endpoints are documented below. You can test live API responses directly using the Try Endpoint button.

GET /ping Render & Uptime Keep-Alive Ping

Ultra-fast 1ms ping endpoint used by UptimeRobot, Cron-Job.org, or Render to keep instance awake 24/7.

curl -X GET "http://localhost:8000/ping"
GET /healthz Render Automated Infrastructure Probe

Render load-balancer health check probe endpoint.

curl -X GET "http://localhost:8000/healthz"
GET /health Root System Health Status

Returns health status and render keep-alive verification payload.

curl -X GET "http://localhost:8000/health"
GET /api/v1/health API Health & Neon DB Audit

Checks Neon PostgreSQL connection status and returns active record counts.

curl -X GET "http://localhost:8000/api/v1/health"
GET /api/v1/providers List AI Providers

Returns all 123 AI providers (OpenAI, Anthropic, Google, DeepSeek, Meta, Qwen, etc.).

curl -X GET "http://localhost:8000/api/v1/providers"
GET /api/v1/models Search, Filter & Paginate Models

Filters: search, category (llm, image, video, audio), provider, is_free, is_open_weight, ordering, limit, offset.

curl -X GET "http://localhost:8000/api/v1/models?category=llm&is_open_weight=true&limit=5"
GET /api/v1/models/{path:identifier} Detailed Model Specs & Benchmarks

Retrieves single model detail by OpenRouter ID (e.g. anthropic/claude-3.5-sonnet), slug, or DB ID.

curl -X GET "http://localhost:8000/api/v1/models/anthropic/claude-3.5-sonnet"
GET /api/v1/leaderboard Model Leaderboards & Rankings

Filters: sort_by (intelligence, coding, speed, price), category (all, open-llm, free, weekly-top-10).

curl -X GET "http://localhost:8000/api/v1/leaderboard?sort_by=coding&category=all"
GET /api/v1/compare Side-by-Side Model Comparison

Side-by-side comparison between model_a and model_b (specs, prices, coding index, TPS).

curl -X GET "http://localhost:8000/api/v1/compare?model_a=anthropic/claude-3.5-sonnet&model_b=deepseek/deepseek-r1"
POST /api/v1/sync Trigger Master Sync Pipeline

Triggers complete OpenRouter catalog + Artificial Analysis + Null Backfill ingestion pipeline.

curl -X POST "http://localhost:8000/api/v1/sync"

Data Models & Entity Relationships

RankLLMs Engine organizes AI entities into 6 core PostgreSQL models:

  • LLMModel: Primary registry entity (`openrouter_id`, `slug`, `name`, `provider`, `category`, `is_open_weight`, `is_free`).
  • ModelSpecification: OneToOne with LLMModel (`context_length`, `max_completion_tokens`, `supports_vision`, `supports_tools`).
  • ModelPricing: OneToOne with LLMModel (`prompt_price_per_1m`, `completion_price_per_1m`).
  • ModelBenchmark: OneToOne with LLMModel (`intelligence_index`, `coding_index`, `agentic_index`, `tokens_per_second`, `arena_elo`).
  • AppRanking: Top 50 AI applications ranked by monthly token usage.
  • TaskClassification: Task distribution percentages (Code Generation, Debugging, Workflow Execution).

Data Pipelines & APScheduler

The engine executes `run_master_sync()` periodically every 6 hours using APScheduler in background process.

Render Deployment & 24/7 Keep-Alive

To prevent Render free tier sleeping after 15 minutes of inactivity, set an uptime pinger to hit /ping or /health every 5 minutes on UptimeRobot or Cron-Job.org.

Pro Suggestions to Elevate RankLLMs Engine

🚀
1. Redis / In-Memory Response Caching
Add 5-minute Django cache headers or Redis caching for high-traffic leaderboard endpoints (/api/v1/leaderboard, /api/v1/models) to reduce database queries to near 0ms for frontend users.
🔑
2. API Keys & Rate Limiting (API Monetization)
Add API key authentication (`X-API-Key`) with tiered rate-limiting (e.g. Free Tier: 60 req/min, Pro Tier: 1000 req/min) if you plan to offer RankLLMs Data API to third-party developers.
📊
3. Export Leaderboard to CSV / JSON
Add an /api/v1/export?format=csv endpoint so developers and researchers can download the entire benchmark matrix as a CSV spreadsheet.
🔔
4. Discord / Webhook Alerts on New Model Releases
Whenever sync_all detects a brand-new model (e.g. Claude 4, GPT-5, DeepSeek R2), send an automated Discord or Slack webhook notification.
