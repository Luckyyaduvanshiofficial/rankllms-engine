Where the numbers come from

Each source is ingested raw and shown unmodified on its own page. Only then is anything merged, so you can audit the join.

  1. Ingested

    • OpenRouter — catalog + benchmarks
    • Artificial Analysis — independent indices
    • models.dev 0 provider metadata

  2. Normalized

    Slugs, providers, and benchmark fields are reconciled across feeds into one schema.

  3. Source of truth

    rankindex — one row per model, every score traceable to its source.

    View the matrix

  4. Served

    Free JSON API. No key required on public routes.
