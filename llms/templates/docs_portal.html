How the data is structured

OpenRouter Artificial Analysis models.dev → Raw source pages (as-is) → Merge + normalize → rankllms source of truth → Leaderboard API

API Endpoints

GET /api/v1/leaderboard Main leaderboard ranked by intelligence
GET /api/v1/rankindex Merged source-of-truth master table
GET /api/v1/benchmarks Benchmark evaluation matrix
GET /api/v1/models Query and filter all models
GET /api/v1/providers List of AI providers
GET /api/v1/health System health check
